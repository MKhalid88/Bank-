# 🏦 Simple Bank Management System (Python OOP)

A lightweight, interactive Command Line Interface (CLI) banking application built in Python. This project demonstrates core Object-Oriented Programming (OOP) principles including **Encapsulation**, **Properties (Getters & Setters)**, **Class Attributes**, and structured control flow.

---

## ✨ Features

- **Account Creation**: Interactive creation of new bank accounts with customer details and initial balance.
- **Deposit & Withdraw Operations**: Perform financial transactions with built-in validation checks (e.g., non-negative amounts, insufficient funds).
- **Account Lookup**: View all registered accounts and select specific accounts for dynamic operations.
- **Global Account Tracking**: Real-time counter monitoring total accounts generated using class attributes.
- **Data Protection**: Encapsulated balance management using Python `@property` decorators.

---

## 🛠️ Concepts Demonstrated

- **Encapsulation**: Protected attributes (`_balance`) to prevent unauthorized modification.
- **Property Decorators**: Controlled access to data via `@property` and `@balance.setter`.
- **Class vs Instance Attributes**: Tracking shared data (`account_count`) across all instances.
- **Input Validation & Error Handling**: Guard clauses to prevent logical errors during banking operations.
